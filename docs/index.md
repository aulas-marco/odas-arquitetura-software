# ODAs de Arquitetura de Software

Este portal reúne os Objetos Digitais de Aprendizagem (ODAs) da disciplina Arquitetura de Backend, do curso de Arquitetura de Software Distribuído do IEC/PUC Minas. Cada ODA é uma página interativa de estudo usada nos encontros ao vivo, depois da exposição do professor, e acompanha um módulo do [material oficial da disciplina](https://marco-mendes.github.io/arquitetura-software/).

Cada ODA tem 25 minutos e quatro etapas: Objetivo (2 minutos), Conceitos (8 minutos), Laboratório (12 minutos) e Verificação (3 minutos). O Laboratório executa programas Python já prontos, guardados na pasta `codigo/` deste repositório, e não exige que o aluno escreva código. Cada etapa termina com os links para as seções do material oficial que ela cobre, e a página [Rastreabilidade](rastreabilidade.md) reúne essa correspondência numa tabela.

Antes do primeiro encontro, conclua o [Módulo 0](modulo-0/index.md), que instala o Git, o VS Code e o Python e clona este repositório.
