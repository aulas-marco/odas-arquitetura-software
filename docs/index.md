# ODAs de Arquitetura de Software

Este portal reúne os Objetos Digitais de Aprendizagem (ODAs) da disciplina Arquitetura de Backend, do curso de Arquitetura de Software Distribuído do IEC/PUC Minas. Cada ODA é uma página interativa de estudo usada nos encontros ao vivo depois da exposição do professor, e cada uma acompanha um módulo do [material oficial da disciplina](https://marco-mendes.github.io/arquitetura-software/).

| Etapa | Duração |
| --- | --- |
| Objetivo | 2 minutos |
| Conceitos | 8 minutos |
| Laboratório | 12 minutos |
| Verificação | 3 minutos |

O Laboratório executa programas Python prontos, guardados na pasta `codigo/` deste repositório, e o aluno lê a saída de cada programa sem precisar escrever código. Cada etapa termina com os links para as seções correspondentes do material oficial, e a página [Rastreabilidade](rastreabilidade.md) reúne essa correspondência numa tabela única.

O [Módulo 0](modulo-0/index.md) instala o Git, o VS Code e o Python e clona este repositório, e deve ser concluído antes do primeiro encontro.

O catálogo abaixo é gerado a partir do arquivo `catalogo/odas.yml`, e o progresso de cada ODA fica gravado somente no navegador de quem a estuda.
