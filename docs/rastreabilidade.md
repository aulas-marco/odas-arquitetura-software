# Rastreabilidade

Esta página liga cada etapa das ODAs às seções do [material oficial da disciplina](https://marco-mendes.github.io/arquitetura-software/) e aos arquivos de código que materializam cada conceito. Os links de código apontam para o commit `00419ea` deste repositório, o mesmo citado nas ODAs. As seções do material oficial correspondem ao commit `919ad2b` do repositório `marco-mendes/arquitetura-software` para o Módulo 1 , à seção Elegibilidade em quatro estilos de API para o Módulo 2 e às páginas Conceitos, Padrões e decisões e Oficina de ferramentas para o Módulo 3.
